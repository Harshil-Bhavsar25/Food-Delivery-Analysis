# Food-Delivery-Analysis

A data-driven project focused on analyzing real-world food delivery performance using SQL, Python, and Power BI. The goal is to identify patterns, operational challenges, and efficiency metrics across cities, traffic, weather conditions etc.


# Project Structure

- food_delivery_data.csv – A dataset containing order-level details (time taken, vehicle type, city, traffic, weather, etc.).
- Hands on Project 2(Food_Delivery_Analysis).ipynb – Python notebook for data exploration, feature engineering, and visualization.
- food_delivery_query.sql – SQL scripts performing queries on delivery patterns, traffic/weather impact, and time analysis.
- food_delivery_analysis.pbix – Power BI report with interactive dashboards for insights visualization.

# Tools & Technologies

- SQL (MySQL): Data querying and KPI generation
- Python (Pandas, Matplotlib, Seaborn): Data analysis and EDA
- Power BI: Dashboard creation and storytelling
- Jupyter Notebook: Interactive analysis workflow

# Key Insights

- As a basic logic or basic knowledge we analyse that delivery times increase significantly during high traffic density and adverse weather conditions like fog or   cloudy.
- Surprisingly not a adult(20-27 age) but a younger delivery people(29-36 age) with better vehicle conditions tend to deliver faster and receive higher ratings.
- Metropolitan city area have more deliveries compare to urban and semi-urban but at urban areas there is less dilivery time compare to metropoliton and
  semi-urban.
- According to calculation Meals and snacks as food orders are the most frequently and more ordered food types among total orders.

# Highlights

- Generated performance KPIs: avg. delivery time by city, weather, vehicle, order type, and traffic.
- Created visual dashboards comparing delivery performance over time and across conditions.
- Built SQL queries to assess seasonal impact, vehicle condition, and ratings relationship.
